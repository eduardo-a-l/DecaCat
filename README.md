# DecaCat

A 2D top-down roguelike made with Unity. You play as a cat fighting through procedurally generated floors of rooms, picking up weapons and powers along the way.

## Requirements

- Unity 6000.4.10f1
- Windows Build Support and Android Build Support modules, if you want to build for those platforms

## Getting started

1. Clone the repository.
2. Open the project folder with Unity Hub.
3. Open the `MainMenu` scene and press Play.

## Building

Use the **DecaCat > Build** menu in the Unity editor, or run `build.bat` from the command line with `windows`, `apk`, `aab` or `all`.
